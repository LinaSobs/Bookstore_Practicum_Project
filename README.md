# Boox Store

A single-page website for an independent bookstore, built with plain HTML5 and CSS3 (no frameworks).

## Features

- Book grid split into Fiction, Nonfiction and Staff Picks
- Events section for readings and book clubs
- Sticky header with working in-page navigation
- Fully responsive with no horizontal scroll on phone, tablet or desktop

## Tech

- Semantic HTML5 landmarks: `header`, `nav`, `main`, `section`, `article`, `footer`
- CSS custom properties (variables) for all colors
- `box-sizing: border-box` applied globally
- **CSS Grid** for the book cards (`repeat(auto-fill, minmax(...))`)
- **Flexbox** for the header, nav, event rows and card layout

## Run it

Open `index.html` in a browser.
